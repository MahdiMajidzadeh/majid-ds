mds:color-picker

A colour picker — an open version of a Flux Pro component.

A saturation/brightness canvas, hue and alpha sliders, a swatch palette, an eyedropper and six output formats. Live — open it.

Brand color 
<mds:color-picker
    label="Brand color"
    value="#e11d48"
    name="brand_color"
    clearable
    dropper
    class="max-w-xs"
/>

Output format

Options are hex, hexa, rgb, rgba, hsl and hsla. The alpha formats add the transparency slider.

Background (rgba)
Output format: rgba, with an alpha slider 
<mds:color-picker
    label="Background (rgba)"
    description="Output format: rgba, with an alpha slider"
    value="rgba(59, 130, 246, 0.5)"
    format="rgba"
    class="max-w-xs"
/>

Custom swatches

Custom swatches 
<mds:color-picker
    label="Custom swatches"
    value="#00c16a"
    :swatches="[['#ef4444', 'Red'], ['#f59e0b', 'Amber'], ['#00c16a', 'Green'], ['#3b82f6', 'Blue'], ['#000000', 'Black']]"
    class="max-w-xs"
/>

Button mode

type="button" shows just a swatch, for a toolbar.

 
<div class="flex items-center gap-3">
    <mds:color-picker type="button" value="#8b5cf6" />
    <mds:color-picker type="button" />
</div>

Reference

mds:color-picker

PropDescription
valueInitial colour, in any supported format.
formatOutput format: hex, hexa, rgb, rgba, hsl, hsla. Default: hex.
typeOptions: input, button. Default: input.
labelField label.
descriptionSmaller text under the label.
placeholderPlaceholder for the text field.
swatchesArray of colours, or of [colour, label] pairs.
dropperAdds the eyedropper button where the browser supports it. Default: false.
clearableAdds a clear button. Default: false.
sizeOptions: sm.
disabledDisables the control.
invalidMarks the control as invalid.
nameField name for a plain form.
wire:modelBinds to a Livewire property.
