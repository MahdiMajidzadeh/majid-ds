mds:pillbox

A multi-select whose chosen values become removable pills — an open version of a Flux Pro component.

Flux's Pillbox is Pro-only. This is a working replacement: type to filter, click or press Enter to take a value, and every choice becomes a pill you can drop again. The preview is live — the list opens when the field takes focus.

Capped, disabled and empty

A max locks every unchosen option once the cap is reached — the chosen ones stay removable. A single option can be disabled on its own, and empty sets the line shown when the filter matches nothing.

Livewire and validation

The machine value is a visually hidden <select multiple>, which Livewire reads as an array, so wire:model goes straight on the component. An error — or the message the validation bag holds for name — is rendered under the field and marks it invalid.

Persian output

The built-in microcopy — the field's accessible name, the clear and remove labels, the no-match line and the announced count — follows config('mds.persian_digits'), which is on by default in a real app and off in these docs. :fa="true" forces it on for one pillbox. Search folds Arabic ي/ك into ی/ک and Persian digits into Latin, so «کتاب» matches «كتاب».

Reference

mds:pillbox

PropDescription
valueThe chosen values: an array, or a comma-separated string.
namePosts as name[], and is the key the validation bag is read with. Defaults to the wire:model value.
labelField label. It also names the listbox.
descriptionHelper text under the field.
placeholderPlaceholder shown while nothing is chosen.
search-labelAccessible name of the text field. Default: the label, else "Search" / جستجو.
clearableAdds a clear-all button. Default: false.
maxMost values that may be chosen. Unbounded when absent.
emptyLine shown when the filter matches nothing. Default: "No matches." / موردی یافت نشد. — :empty="false" hides the popup instead.
disabledDefault: false.
invalidMarks the field invalid without a message.
errorMessage to show; falls back to $errors->first($name).
faLanguage of the built-in strings. Default: config('mds.persian_digits').

mds:pillbox.option

PropDescription
valueThe value this row selects. Default: the row's own text.
disabledShown but not selectable. Default: false.
