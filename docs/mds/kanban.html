mds:kanban

A drag-and-drop board that also works entirely from the keyboard — an open version of a Flux Pro component.

Flux's Kanban component is Pro-only. This is a working replacement with no third-party JavaScript: the dragging is Pointer Events in the kit's own Alpine. The preview is live — drag a card with the mouse, or click one and press Space, then the arrow keys.

The keyboard

Drag-and-drop that only works with a mouse is half a component. The board is one tab stop (a roving tabindex); from there Space or Enter picks a card up, the arrow keys move it — up and down inside the column, left and right between columns — Home and End send it to the top or the bottom, Space drops it and Esc puts it back. Every step is announced in a polite live region: “Fix the cart badge” moved to position 2 of 3 in “In progress”. The horizontal keys follow what you see rather than the source order, so on an RTL page they are mirrored.

Work-in-progress limits

A column with a limit counts against it — «2 of 3 cards» — and says so when it goes over: the badge turns red and gains a warning icon, and the column's accessible name ends with “Over limit”. Nothing here is carried by colour alone. Drag a third card into the middle column to see it.

Empty columns, locked cards, a locked board

An empty column keeps its drop zone and says so. A card marked disabled stays readable and focusable but cannot be picked up or dragged; disabled on the board itself freezes everything. Both are stated in the markup (aria-disabled), not only in the styling.

Livewire

Each column carries a hidden multiple <select> holding its card ids in order, and wire:model on the column is forwarded to it — Livewire reads a multiple select as an array, so the bound property is the ordered list. Bind one slice of the board per column. The board also fires a bubbling mds-kanban-moved event whose detail is { card, from, to, index }, so a single move can be persisted without diffing anything. A server-side change of the arrays travels the other way: a MutationObserver re-reads the options after the morph and re-orders the cards to match.

    <p class="mt-3 text-sm text-zinc-500">Last move: <span x-text="last || '—'"></span></p>
</div>
The Blade above is the whole client half; on the server it is public array $board = ['todo' => ['1', '2'], 'doing' => ['3']];. Give each card a wire:key using the <x-mds::kanban.card> spelling — Livewire rewrites wire:key before the mds: tag compiler sees the tag.

Persian output

On an RTL page the columns run right to left and the arrow keys follow them: ← moves a card to the next column, not the previous one. The built-in strings — the board's name, the keyboard hint, the card count, the empty placeholder and every announcement — follow config('mds.persian_digits'), which is on by default in a real app and off in these docs, so this example forces it back on with :fa="true".

Reference

mds:kanban

PropDescription
labelAccessible name of the board. Default: "Kanban board", or تخته کانبان in Persian.
disabledFreezes the board — nothing can be picked up or dragged. Default: false.
faPersian digits and strings. Default: config('mds.persian_digits'); inherited by columns and cards.

mds:kanban.column

PropDescription
keyThe column's id in the board state and in the mds-kanban-moved event. Falls back to name, then to a hash of heading.
headingVisible column title, and the column name the announcements read out.
nameForm name of the hidden control; [] is appended, and it is the key the error bag is read with.
limitWork-in-progress limit. The badge reads "2 of 3 cards" and going over flags the column.
emptyPlaceholder for an empty column. Default: "No cards", or کارتی نیست in Persian.
errorValidation message under the column. Falls back to the error bag when name is set.
invalidMarks the column invalid without a message. Default: false.
faPersian digits and strings; inherited from the board.

mds:kanban.card

PropDescription
keyThe card's id in the board state. Derived from the card's own content when omitted.
headingBold title line, and the card's name in the announcements.
disabledThe card cannot be moved — still focusable and readable. Default: false.
faPersian digits and strings; inherited from the board.
