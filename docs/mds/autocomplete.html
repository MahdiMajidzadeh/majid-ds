mds:autocomplete

A text field with suggestions — an open version of a Flux Pro component.

Flux's Autocomplete is Pro-only. This is a working replacement: a real flux:input that keeps whatever the user types, with a filtered list of suggestions underneath. Unlike a select it never forces a choice — the options are a shortcut, not a constraint. The preview is live; type a letter or two into it.

Matching folds Persian and Arabic spellings together (ي/ى → ی, ك → ک) and both digit scripts to Latin, so a shopper typing كتاب on an Arabic keyboard still finds کتاب.

Empty state

Without empty the list simply disappears when nothing matches. A bare empty attribute shows the built-in line, and a string replaces it. Type something that matches nothing to see it.

Strict values

Free text is the default. strict makes the field settle on an option when it loses focus: text that matches one is snapped to that option's own spelling, and text that matches none is cleared. Type tehran and click away.

Tehran
Mashhad
Isfahan
No matches. 
<mds:autocomplete label="City" placeholder="Only a listed city is kept" strict empty class="max-w-sm">
    <mds:autocomplete.item>Tehran</mds:autocomplete.item>
    <mds:autocomplete.item>Mashhad</mds:autocomplete.item>
    <mds:autocomplete.item>Isfahan</mds:autocomplete.item>
</mds:autocomplete>

Validation

Pass error for an explicit message. With a name (or a wire:model to take the name from) and no error, the component reads the message out of the validation bag itself.

With Livewire

The bound property holds the text, so the options can be queried on the server as it changes. Nothing else is needed — the component re-scans its own list when Livewire morphs new items in.

City
Tehran
Tabriz
No matches. 
<mds:autocomplete wire:model.live.debounce.300ms="city" name="city" label="City" icon="map-pin"
                  placeholder="Start typing..." :min-chars="2" clearable empty class="max-w-sm">
    <mds:autocomplete.item>Tehran</mds:autocomplete.item>
    <mds:autocomplete.item>Tabriz</mds:autocomplete.item>
</mds:autocomplete>
In the component: public string $city = ''; and a computed property that queries with $this->city. Because the value is free text, validate it server-side even when strict is on — the browser is not the authority.

Reference

mds:autocomplete

PropDescription
valueInitial text in the field.
nameField name for a plain form post, and the key the error bag is read with. Defaults to the wire:model expression.
labelLabel text. Also names the suggestion listbox.
descriptionHelp text under the field.
placeholderPlaceholder for the field.
iconLeading icon name.
clearableAdds a button that empties the field. Default: false.
min-charsCharacters needed before the list opens. Default: 0.
emptyMessage shown when nothing matches. Absent, the list just hides; a bare attribute uses "No matches.", or موردی یافت نشد. in Persian.
strictOn blur, snap the text to a matching option or clear it. Default: false.
sizeField size: sm or xs.
disabledDisables the field and hides the popup.
invalidApplies error styling.
errorValidation message. Falls back to the bag for name.
faPersian built-in strings. Default: config('mds.persian_digits').
wire:modelBinds the text to a Livewire property.

mds:autocomplete.item

PropDescription
valueText written into the field when the option is picked. Defaults to the option's own text.
disabledLists the option but does not let it be picked. Default: false.
faInherited from the autocomplete.
