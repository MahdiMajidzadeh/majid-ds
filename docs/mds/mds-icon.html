mds components

mds:icon

Hugeicons, replacing heroicons across every mds component.

The free Stroke Rounded set (6,200 icons) ships with the package. Names come straight from hugeicons.com.

<mds:icon icon="shopping-cart-01" />
<mds:icon icon="truck-delivery" />
<mds:icon icon="discount-tag-01" />
<mds:icon icon="wallet-01" />
<mds:icon icon="store-01" />

heroicon names still work

An alias map means you can keep writing heroicon names and get the Hugeicons equivalent, so switching an existing app over is a one-line config change rather than a find-and-replace.

<mds:icon icon="magnifying-glass" />
<mds:icon icon="shopping-bag" />
<mds:icon icon="credit-card" />
<mds:icon icon="exclamation-triangle" />

Size and color

Size with Tailwind classes; the glyph inherits currentColor.

<div class="flex items-end gap-3 text-zinc-600 dark:text-zinc-300">
    <mds:icon icon="package" class="size-4" />
    <mds:icon icon="package" class="size-6" />
    <mds:icon icon="package" class="size-8" />
    <mds:icon icon="package" class="size-10 text-accent" />
</div>

Accessible label

An icon carrying meaning on its own needs a label; a decorative one should stay unlabelled so screen readers skip it.

<div class="flex items-center gap-3">
    <mds:icon icon="checkmark-circle-02" class="size-8 text-green-500" label="Confirmed" />
    <mds:icon icon="alert-02" class="size-8 text-amber-500" label="Warning" />
    <mds:icon icon="cancel-circle" class="size-8 text-red-500" label="Error" />
</div>

Pro styles

Only Stroke Rounded is free. For the other eight styles, register your own licensed export — this package ships no Pro files.

config/mds.php
// config/mds.php
'icons' => [
    'default' => 'hugeicons',
    'style' => 'stroke-rounded',
    'sets' => [
        'solid-rounded' => resource_path('svg/hugeicons/solid-rounded'),
    ],
],
Set config('mds.icons.default') to flux to go back to heroicons everywhere.

Strict mode (no heroicons fallback)

By default, a name neither Hugeicons nor the alias map covers still renders — as a heroicon, via flux:icon. If a page only ever calls mds:icon and you want a hard guarantee that heroicons never render, set strict instead of relying on every call site using a name Hugeicons actually has.

config/mds.php
// config/mds.php
'icons' => [
    'strict' => true,
],
An unmapped name then renders nothing instead of falling back to flux:icon.

In RTL

An icon has no digits or text of its own, so nothing here reads config('mds.persian_digits') and the glyph never mirrors. On an RTL page only the accessible label needs translating.

<div class="flex items-center gap-3">
    <mds:icon icon="checkmark-circle-02" class="size-8 text-green-500" label="تأیید شد" />
    <mds:icon icon="alert-02" class="size-8 text-amber-500" label="هشدار" />
    <mds:icon icon="truck-delivery" class="size-8 text-zinc-500" label="در حال ارسال" />
</div>

mds:icon

PropDescription
iconHugeicons name, or a heroicon name via the alias map.
variantHugeicons style. Falls back to Stroke Rounded when a Pro style is not registered.
strokeStroke width. Default: 1.5.
labelAccessible label. Without it the icon is aria-hidden.
