mds:editor

A rich-text field — an open version of a Flux Pro component.

A contenteditable surface under a real ARIA toolbar. No TipTap, no ProseMirror, no third-party JavaScript at all — the marks are the browser's own editing commands, and what the field stores is filtered down to a fixed allow-list on the way in and on the way out. Live: type in it, select a word, press the toolbar.

Product story
Write the story...
Formatting is limited on purpose — everything else is stripped. 
<mds:editor
    name="story"
    label="Product story"
    description="Formatting is limited on purpose — everything else is stripped."
    placeholder="Write the story..."
    rows="7"
/>

What it supports

Bold, italic, underline, strikethrough, three heading levels, paragraphs, bulleted and numbered lists, a quote, a code block, links, per-block text direction and clear-formatting. That is the whole vocabulary: p h1 h2 h3 ul ol li blockquote pre strong em u s code a br, an href on a link and a dir on a block. There are no images, tables, colours or alignment — a paste that carries them keeps its text and loses the rest.

Everything the toolbar can make 
<mds:editor
    label="Everything the toolbar can make"
    :value="'<h2>A heading</h2>'
        .'<p>Text with <strong>bold</strong>, <em>italic</em>, <u>underline</u>, <s>strikethrough</s> and a <a href=\'https://laravel.com\'>link</a>.</p>'
        .'<ul><li>A bulleted item</li><li>Another one</li></ul>'
        .'<blockquote>A quoted line.</blockquote>'
        .'<pre>php artisan serve</pre>'"
    rows="10"
/>
The value is put into a hidden input as an escaped attribute and painted onto the surface through the sanitiser — the stored HTML is never echoed as markup, so a poisoned value cannot execute.

Choosing the tools

The toolbar prop takes a space-separated list; | is a separator. Pass :toolbar="false" for a bare surface.

Comment
Keep it short...
 Plain notes
No toolbar at all...
 
<div class="space-y-4">
    <mds:editor label="Comment" toolbar="bold italic | link unlink" rows="3" placeholder="Keep it short..." />

    <mds:editor label="Plain notes" :toolbar="false" rows="3" placeholder="No toolbar at all..." />
</div>

Composing your own toolbar

The default slot replaces the built-in layout. <mds:editor.button> knows every command's icon and label, and its own slot replaces the icon — so a custom button is one line.

Custom toolbar
Two marks and a heading...
<mds:editor label="Custom toolbar" rows="4" placeholder="Two marks and a heading...">
    <mds:editor.toolbar label="Formatting">
        <mds:editor.button command="bold" />
        <mds:editor.button command="italic" />
        <mds:editor.button command="h2" />
        <mds:editor.button command="clear" label="Start over" />
    </mds:editor.toolbar>

    <mds:editor.content placeholder="Two marks and a heading..." rows="4" />
</mds:editor>

Keyboard

In the text: Ctrl/⌘+B, I, U, K (link), \ (clear), Shift+X (strikethrough), Shift+7 / 8 (numbered / bulleted list). Tab is left alone, so it moves focus out. In the toolbar: it is one tab stop, and ← / → move between the buttons in the order you see them — flipped on an RTL page — with Home and End for the ends.

Validation

An explicit error renders the message; without one, a name falls back to $errors->first($name). Either way the surface gets aria-invalid and the box turns red.

Description
Say something about it...
The description is required. 
<mds:editor
    label="Description"
    name="description"
    error="The description is required."
    rows="3"
    placeholder="Say something about it..."
/>

In RTL

The whole control mirrors, the list and quote icons flip, and the toolbar's arrow keys follow what you see. The direction tool sets dir on the block the caret is in, so one Persian document can hold an LTR code block or an English quotation. Built-in labels follow config('mds.persian_digits') — on by default in a real app, off in these docs.

متن آگهی
داستان محصول را بنویسید...
نوار ابزار را روی متن انتخاب‌شده اعمال کنید 
<mds:editor
    label="متن آگهی"
    description="نوار ابزار را روی متن انتخاب‌شده اعمال کنید"
    placeholder="داستان محصول را بنویسید..."
    dir="rtl"
    rows="7"
    :value="'<p>این یک بند فارسی است.</p><p dir=\'ltr\'>And this block is left to right.</p>'"
/>

Reference

mds:editor

PropDescription
valueInitial HTML. Filtered through the allow-list before it is shown.
placeholderShown while the surface is empty.
labelField label. Also names the editing surface.
descriptionSmaller text under the label.
toolbarSpace-separated tool list, | for a separator, or false for none.
toolbar-labelThe toolbar's accessible name.
rowsStarting height in lines. Default: 6.
dirBase direction of the surface: ltr, rtl, auto.
disabledMakes the whole control inert and the surface uneditable.
invalidMarks the control as invalid.
errorValidation message. Falls back to the error bag for name.
nameField name for a plain form, and the key errors are read with.
wire:modelBinds the HTML to a Livewire property.

mds:editor.toolbar

PropDescription
toolsThe tool list, when you are not passing it on the parent.
labelAccessible name of the toolbar.

mds:editor.button

PropDescription
commandThe tool: bold, italic, underline, strike, h1, h2, h3, paragraph, bullet, ordered, quote, code, link, unlink, direction, clear.
iconOverrides the command's own icon.
labelOverrides the command's built-in accessible name.
toggleWhether the button reports aria-pressed. Defaults per command.

mds:editor.content

PropDescription
placeholderShown while the surface is empty.
rowsStarting height in lines. Default: 6.
dirBase direction of the surface.
labelAccessible name of the surface.
disabledRenders contenteditable="false".
invalidAdds aria-invalid.
