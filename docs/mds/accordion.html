mds components

mds:accordion

Collapsible sections built on native details/summary — an open version of a Flux Pro component.

Flux's Accordion component is Pro-only. This is a working replacement, and it is deliberately thin: every item is a real <details>/<summary> pair, so opening and closing, Enter and Space, focus and browser find-in-page all come from the platform — and keep working with JavaScript off. The preview is live.

One at a time

Add exclusive and opening one item closes the others. It is the native <details name> group doing the work, so it holds before any script has run; each accordion gets its own group, and nesting one inside another keeps the two apart. Pass name to choose the group name yourself.

Animated

transition animates the height of the body over 200ms instead of snapping it open. The tween is skipped under prefers-reduced-motion, where the item toggles natively — and re-opening halfway through a collapse grows back from wherever the box has got to.

Open and disabled items

expanded renders the open attribute server-side, so the first paint is already right — no flash of a closed section. disabled takes an item out of the tab order and refuses to open it; it is the state to use for a section that is not ready yet, not a way to hide content.

Headings with markup

The heading prop is a shortcut, and its text is escaped. When the heading needs more than a string — a badge, an icon, a count — write the two subcomponents out instead.

2 items
Handed to the courier on Sunday.
Order 1477 — delivered

In RTL

The accordion has no built-in strings and prints no digits of its own, so nothing here switches language — the layout simply mirrors: the chevron moves to the left edge and the heading text starts on the right. The copy, and any digits in it, are yours.

Reference

mds:accordion

The group. Renders a divided list; adds no behaviour of its own beyond the group name.

PropDescription
exclusiveOnly one item open at a time, through the native <details name> group. Default: false.
transitionAnimate the open/close height. Default: false.
nameThe group name to use when exclusive. Generated per accordion when omitted.

mds:accordion.item

One <details>. With heading it renders the heading and content parts for you; otherwise put them in the slot yourself.

PropDescription
headingHeading text (escaped). Omit it and compose the two subcomponents instead.
expandedRender the item open. Default: false.
disabledNot focusable, and refuses to toggle. Default: false.

mds:accordion.heading

The <summary> — the toggle. Takes the item's state from it; adds the rotating chevron. Takes no props of its own.

mds:accordion.content

The body. Its padding sits on an inner box, so the height animation can run the outer element down to zero. Takes no props of its own.
