mds:command

A ⌘K command palette — an open version of a Flux Pro component.

Flux's Command component is Pro-only. This is a working replacement with Persian search, keyboard navigation and a ⌘K shortcut. The preview is live — type in it.

Reference

mds:command

The palette shell. Takes no props.

mds:command.input

PropDescription
placeholderPlaceholder text.
iconLeading icon. Default: magnifying-glass.
clearableAdds a clear button. Default: false.
closableAdds a close button, for use inside a modal. Default: false.
autofocusFocuses the field on open.
clear-labelAccessible label for the clear button.
close-labelAccessible label for the close button.

mds:command.items

PropDescription
emptyMessage shown when the search matches nothing.

mds:command.heading

A group label inside the list.

mds:command.item

PropDescription
iconLeading icon name.
kbdKeyboard shortcut hint on the trailing edge.
hrefRenders the item as a link.
