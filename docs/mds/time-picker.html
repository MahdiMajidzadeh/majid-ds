mds:time-picker

A typable time field over a list of times — an open version of a Flux Pro component.

A combobox: type a time, or pick one from the list. The field shows the time the way your app reads it; a hidden input carries the machine value — always 24-hour HH:MM with Latin digits, whatever is displayed. The preview is live — click it and try typing 1430.

Typing is lenient: 1430, 14:30, 2:30 pm, ۱۴:۳۰ and ۲:۳۰ ب.ظ all land on the same value. Text that is not a time reverts to the last valid one on Enter or blur.

Keyboard

With the list open the arrows preview an option in the field and Enter commits it; Home and End jump to the ends. With the list closed the arrows nudge the value itself by step. Alt + arrow opens and closes the list, Escape reverts what you typed, and Tab leaves it committed.

Persian output

config('mds.persian_digits') — on by default in a real app, off in these docs — switches the digits and the built-in words to Persian; :fa="true" does it for a single picker. The field and the list stay dir="ltr", because a time reads hour-then-minute in both languages, and sit end-aligned in an RTL form. The hidden value is Latin regardless.

Reference

mds:time-picker

PropDescription
valueInitial time. HH:MM, H:MM or HH:MM:SS, Persian digits accepted; anything else renders empty.
nameField name for a plain form post, and the key the error bag is read with. Lands on the hidden input.
labelLabel text. Also names the listbox.
descriptionHelp text under the field.
placeholderPlaceholder for the field. Default: --:--.
stepMinutes between listed times, and the arrow-key increment. Default: 30.
minEarliest listed time, and the floor a typed time is clamped to. Default: 00:00.
maxLatest listed time, and the ceiling a typed time is clamped to. Default: 23:59.
hours12 for a 12-hour display with AM/PM. Default: 24.
clearableAdds a clear button once there is a value. Default: false.
disabledMakes the whole control inert. Default: false.
sizesm for a compact field.
iconLeading icon. false removes it. Default: clock.
invalidApplies error styling.
errorValidation message. Falls back to the bag for name.
faPersian digits and Persian AM/PM words. Default: config('mds.persian_digits').
wire:modelBinds the hidden HH:MM value to a Livewire property.
