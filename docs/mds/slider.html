mds components

mds:slider

A one- or two-thumb range slider — an open version of a Flux Pro component.

A native <input type="range"> under the kit's styling, so the keyboard, the pointer and the screen-reader announcement are the browser's own. show-value adds a live readout beside the label. The preview is live — drag it, or focus it and press the arrow keys.

Volume 60%
Arrow keys move it too. 
<mds:slider label="Volume" description="Arrow keys move it too." :value="60" :step="5" format="{value}%" show-value class="max-w-md" />
Nothing is clamped in JavaScript alone: the value is clamped to min/max and snapped to the step grid on the server as well, so the first paint, a no-JS form post and the thumb never disagree.

Range

Add range and pass [low, high]. Two thumbs share one track and may not cross; a press on the bare track moves the nearer one.

Price range 500000 Toman – 3000000 Toman 
<mds:slider range label="Price range" :min="0" :max="5000000" :step="250000" :value="[500000, 3000000]" format="{value} Toman" show-value class="max-w-md" />
An inverted pair like [80, 20] is put back in order rather than rendering a crossed range.

Bounds and step

Any numeric min, max and step — fractions included. A value off the grid is snapped to it.

Rating 3.5
Temperature 21°C 
<div class="w-full max-w-md space-y-6">
    <mds:slider label="Rating" :min="1" :max="5" :step="0.5" :value="3.5" show-value />
    <mds:slider label="Temperature" :min="-20" :max="40" :step="1" :value="21" format="{value}°C" show-value />
</div>

Ticks

Not in Flux: ticks draws one mark per step while the span divides into at most twenty whole steps — and quietly draws none when they would crowd the track. An integer asks for that many, evenly spaced.

Screen brightness 3
Progress 40 
<div class="w-full max-w-md space-y-6">
    <mds:slider label="Screen brightness" :min="1" :max="5" :value="3" ticks show-value />
    <mds:slider label="Progress" :ticks="5" :value="40" show-value />
</div>
Ticks are decoration — aria-hidden and never a substitute for step, which is what actually constrains the value.

Formatting the readout

format is a {value} template. It shapes the readout and the aria-valuetext a screen reader announces, and leaves the machine value alone.

Discount 25%
Budget 120 Toman 
<div class="w-full max-w-md space-y-6">
    <mds:slider label="Discount" :value="25" format="{value}%" show-value />
    <mds:slider label="Budget" :min="0" :max="500" :step="10" :value="120" format="{value} Toman" show-value />
</div>

Size and disabled

size="sm" thins the track for dense filter panels. disabled dims the slider and disables every thumb.

Compact 35
Data allowance
Sign in to change this. 
<div class="w-full max-w-md space-y-6">
    <mds:slider size="sm" label="Compact" :value="35" show-value />
    <mds:slider label="Data allowance" :value="10" :max="50" disabled description="Sign in to change this." />
</div>

Validation

An explicit error wins; otherwise the message comes from the error bag for name — and for a range, from name.* as well, because it posts as an array. Either way the thumbs get aria-invalid and the fill turns red.

Price range 10 – 90
Pick a narrower range.
Weight 80 
<div class="w-full max-w-md space-y-6">
    <mds:slider range name="price" label="Price range" :value="[10, 90]" error="Pick a narrower range." show-value />
    <mds:slider label="Weight" :value="80" invalid show-value />
</div>
The message is rendered with the same markup as flux:error — role="alert", linked from every thumb through aria-describedby — without depending on the session error bag.

Livewire

A single slider binds the property as written. A range binds the two ends as dotted paths — wire:model.live="price" becomes price.0 on the low thumb and price.1 on the high one — so the bound property must be an array of two numbers.

Price range 500000 Toman – 3000000 Toman 
<mds:slider wire:model.live="price" range name="price" label="Price range" :min="0" :max="5000000" :step="250000" :value="[500000, 3000000]" format="{value} Toman" show-value class="max-w-md" />
public array $price = [500000, 3000000]; — a scalar property would break the binding. Modifiers are kept: wire:model.live.debounce.500ms="price" reaches both thumbs. A server-side change of the property flows back into the readout and the fill.

Persian output

config('mds.persian_digits') — on by default in a real app, off in these docs — switches the readout to Persian digits and the built-in thumb labels to Persian («مقدار — حداقل» / «مقدار — حداکثر»); :fa="true" does it for a single slider. The machine value stays Latin, whatever is shown.

بازه قیمت ۵۰۰۰۰۰ تومان – ۳۰۰۰۰۰۰ تومان
قیمت‌ها به تومان است.
میزان صدا ۶۰٪ 
<div class="w-full max-w-md space-y-6">
    <mds:slider :fa="true" range label="بازه قیمت" :min="0" :max="5000000" :step="250000" :value="[500000, 3000000]" format="{value} تومان" show-value description="قیمت‌ها به تومان است." />

    <mds:slider :fa="true" label="میزان صدا" :value="60" :step="5" format="{value}٪" ticks show-value />
</div>
The track is RTL-aware: the fill runs from the start edge, and the arrow keys follow the visual order because the native control already does.

Reference

mds:slider

PropDescription
valueCurrent value — a number, or [low, high] with range. Default: min.
minLower bound. Default: 0.
maxUpper bound. Default: 100.
stepGranularity. Default: 1.
rangeTwo thumbs holding a low and a high value. Default: false.
labelLabel text. Also names the thumbs for screen readers.
descriptionHelp text under the track.
nameField name for a plain form post — name[] for a range — and the key the error bag is read with.
sizesm for a thinner track.
disabledDisables every thumb. Default: false.
show-valueLive readout beside the label. Default: false.
tickstrue for one tick per step (up to twenty), or an integer count. Default: false.
format{value} template for the readout and aria-valuetext.
invalidApplies error styling.
errorValidation message. Falls back to the bag for name (and name.* for a range).
faPersian digits and Persian built-in labels. Default: config('mds.persian_digits').
wire:modelBinds the thumb. A range binds property.0 and property.1.
