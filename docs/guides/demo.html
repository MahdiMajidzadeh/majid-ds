Demo

Every component on one page — the free Flux UI set plus the whole mds layer, in English.

This is the workbench demo, rendered through Blade at build time like every other preview in these docs. Everything on it is live: open the modals, press ⌘K, type in the composer. For the kit in the language it is designed for, see the RTL demo.

Some component output is Persian-only
Digits, separators and the currency label follow config('mds.persian_digits') and config('mds.currency'), so they are Latin here. A handful of strings are baked into the kit with no prop to override them, and stay Persian on this page:
• mds:discount-badge — the ٪ sign
• mds:countdown — the unit labels روز / ساعت / دقیقه / ثانیه and the expiry text به پایان رسید
• mds:product-card — ناموجود for an out-of-stock item
• mds:jalali-date — the month names, and the relative dates from Persian::ago()
• the @toman and @jalali directives, which are Persian by definition
