Flux components

OTP input

A one-time-code field, one box per digit.

Codes read left-to-right even on an RTL page, so wrap the input in dir="ltr".

 
<div dir="ltr">
    <flux:otp length="5" />
</div>

With a field

Verification code Sent to 0912 345 6789. 
<flux:field>
    <flux:label>Verification code</flux:label>
    <flux:description>Sent to 0912 345 6789.</flux:description>

    <div dir="ltr">
        <flux:otp length="6" />
    </div>
</flux:field>

Private

Masks the digits as they are typed.

 
<div dir="ltr">
    <flux:otp length="4" private />
</div>

Reference

flux:otp

PropDescription
lengthNumber of digits.
privateMasks the digits. Default: false.
wire:modelBinds to a Livewire property.

flux:otp.group

Groups a run of inputs, for codes split by a separator.

flux:otp.separator

A dash or dot between groups.
