Flux components

Icon

Flux ships the full heroicons set; this kit adds Hugeicons on top.

<div class="flex items-center gap-4 text-zinc-600 dark:text-zinc-300">
    <flux:icon icon="shopping-cart" />
    <flux:icon icon="truck" />
    <flux:icon icon="credit-card" />
    <flux:icon icon="gift" />
</div>

Variants

Four sizes of the same glyph set. outline is 24px, solid is filled 24px, mini is 20px and micro is 16px.

<div class="flex items-center gap-4 text-zinc-600 dark:text-zinc-300">
    <flux:icon icon="star" variant="outline" />
    <flux:icon icon="star" variant="solid" class="text-amber-400" />
    <flux:icon icon="star" variant="mini" />
    <flux:icon icon="star" variant="micro" />
</div>

Sizing

Size with Tailwind classes; the icon inherits currentColor.

<div class="flex items-end gap-3 text-zinc-600 dark:text-zinc-300">
    <flux:icon icon="bell" class="size-4" />
    <flux:icon icon="bell" class="size-6" />
    <flux:icon icon="bell" class="size-8" />
    <flux:icon icon="bell" class="size-10 text-accent" />
</div>

Shorthand

Every icon is also a component of its own.

<div class="flex items-center gap-4 text-zinc-600 dark:text-zinc-300">
    <flux:icon.heart variant="solid" class="text-red-500" />
    <flux:icon.map-pin />
    <flux:icon.loading />
</div>

Hugeicons

This kit replaces heroicons with Hugeicons across every mds:* component, and gives you mds:icon to use them directly. heroicon names still work through an alias map.

<div class="flex items-center gap-4 text-zinc-600 dark:text-zinc-300">
    <mds:icon icon="shopping-cart-01" />
    <mds:icon icon="truck-delivery" />
    <mds:icon icon="discount-tag-01" />
    <mds:icon icon="wallet-01" />
</div>
See mds:icon for stroke widths, the alias map and registering Pro styles.

Reference

flux:icon

PropDescription
iconIcon name, e.g. shopping-cart.
variantOptions: outline, solid, mini, micro. Default: outline.

flux:icon.{name}

Shorthand for a specific icon, e.g. flux:icon.heart.
