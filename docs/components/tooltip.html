Flux components

Tooltip

A short hint on hover or focus.

Hover the button — the previews here are live.

Add to favorites 
<flux:tooltip content="Add to favorites">
    <flux:button icon="heart" square variant="ghost" aria-label="Favorite" />
</flux:tooltip>

Position

Positions are logical, so start and end follow the reading direction.

Above
Below
Trailing edge 
<div class="flex items-center gap-3">
    <flux:tooltip content="Above" position="top">
        <flux:button size="sm">Top</flux:button>
    </flux:tooltip>

    <flux:tooltip content="Below" position="bottom">
        <flux:button size="sm">Bottom</flux:button>
    </flux:tooltip>

    <flux:tooltip content="Trailing edge" position="right">
        <flux:button size="sm">End</flux:button>
    </flux:tooltip>
</div>

Keyboard shortcut

Quick search ⌘K 
<flux:tooltip content="Quick search" kbd="⌘K">
    <flux:button icon="magnifying-glass" square aria-label="Search" />
</flux:tooltip>

Rich content

Use flux:tooltip.content when the hint needs markup, and interactive when it holds a link.

Free over 1,000,000 Toman.

Tehran only for same-day delivery.

<flux:tooltip interactive>
    <flux:button size="sm" icon="information-circle">Shipping</flux:button>

    <flux:tooltip.content class="max-w-64">
        <p>Free over 1,000,000 Toman.</p>
        <p class="mt-1">Tehran only for same-day delivery.</p>
    </flux:tooltip.content>
</flux:tooltip>

On a disabled control

A disabled button does not fire pointer events, so wrap it and explain why it is disabled.

Add an address first 
<flux:tooltip content="Add an address first">
    <flux:button variant="primary" disabled>Checkout</flux:button>
</flux:tooltip>

Reference

flux:tooltip

PropDescription
contentTooltip text. Use the flux:tooltip.content child for markup.
positionOptions: top, right, bottom, left. Default: top.
alignOptions: start, center, end. Default: center.
kbdKeyboard shortcut shown inside the tooltip.
interactiveKeeps the tooltip open while the pointer is inside it.
toggleableOpens on click instead of hover.

flux:tooltip.content

Rich tooltip body, in place of the content prop.
