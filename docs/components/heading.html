Flux components

Heading

Section titles, with a matching subheading.

Order summary
3 items, shipping to Tehran. 
<div>
    <flux:heading>Order summary</flux:heading>
    <flux:subheading>3 items, shipping to Tehran.</flux:subheading>
</div>

Sizes

Large
Base
<div class="space-y-2">
    <flux:heading size="xl">Extra large</flux:heading>
    <flux:heading size="lg">Large</flux:heading>
    <flux:heading>Base</flux:heading>
</div>

Heading level

Size is visual; level sets the actual h1–h6 element, so the document outline stays correct regardless of how big the text looks.

Page title

<flux:heading size="xl" level="1">Page title</flux:heading>

Accent

Paints the heading in your accent color.

Flash deals
<flux:heading size="lg" accent>Flash deals</flux:heading>

With Persian text

Headings pick up Vazirmatn from the --font-sans token the kit sets, so Persian and Latin headings share one type scale.

سفارش‌های من
۳ سفارش در جریان است. 
<div dir="rtl" class="space-y-1">
    <flux:heading size="xl">سفارش‌های من</flux:heading>
    <flux:subheading>۳ سفارش در جریان است.</flux:subheading>
</div>
