Reference

flux:text

PropDescription
sizeOptions: sm, base, lg.
variantOptions: strong, subtle.
colorAny Tailwind color.
inlineRenders a span instead of a p. Default: false.

flux:link

PropDescription
hrefLink target.
externalOpens in a new tab and adds an external-link icon.
variantVisual variant of the link.
accentIf false, inherits the surrounding color. Default: true.
strongBolder link text. Default: false.
