For AI agents

An RTL, Persian-first layer on top of Flux UI

Majid DS extends Flux UI for Laravel Livewire. Every <flux:*> component keeps working untouched; an <mds:*> namespace adds Persian typography and digits, Jalali dates, Toman/Rial money, e-commerce components, and open implementations of two Flux Pro components.

Requires PHP 8.2+, Laravel 11+, Livewire 3, Tailwind CSS v4. livewire/flux (free tier) installs automatically.

Installation

composer require mahdimajidzadeh/ds

The service provider is auto-discovered. Both tag syntaxes work everywhere: <mds:rating /> and the standard <x-mds::rating />.

While the repo is private, add it as a composer repository first — {"type": "vcs", "url": "git@github.com:MahdiMajidzadeh/majid-ds.git"} — or use a path repository during local development.

Stylesheet

In resources/css/app.css, import the Majid DS layer after Tailwind and Flux:

@import 'tailwindcss';
@import '../../vendor/livewire/flux/dist/flux.css';
@import '../../vendor/mahdimajidzadeh/ds/resources/css/mds.css';

@custom-variant dark (&:where(.dark, .dark *));

The layer sets Vazirmatn as --font-sans, ships the [x-cloak] rule, keeps type="tel" and [data-ltr] inputs left-to-right inside RTL forms, and provides the checkerboard/range-slider styles used by mds:color-picker.

Layout

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    @mdsFonts          {{-- Vazirmatn <link> tags --}}
    @vite('resources/css/app.css')
    @fluxAppearance    {{-- dark-mode handling --}}
</head>
<body class="min-h-screen bg-zinc-50 font-sans antialiased dark:bg-zinc-900">
    {{ $slot }}
    @fluxScripts
</body>
</html>
Alpine requirement. The interactive components (quantity, countdown, rating.input, command, color-picker) need Alpine. Livewire injects it on any page that renders a Livewire component; on purely static pages add @livewireScripts.

For production traffic from Iran, self-host Vazirmatn instead of using @mdsFonts (Google Fonts can be slow or blocked).

Customizing views

php artisan vendor:publish --tag=mds-views   # copies to resources/views/mds/
php artisan vendor:publish --tag=mds-assets  # copies mds.css to resources/css/vendor/

App-level views in resources/views/mds/ take precedence over the package's, exactly like Flux's own publish flow. Components use Flux's --color-accent tokens, so a single Flux theme customization restyles both libraries.

MajidDs\Support\Jalali

Dependency-free Jalali (Shamsi) calendar, tested against PHP's intl Persian calendar across a 110-year range.

MethodDescription
Jalali::fromGregorian($gy, $gm, $gd)→ [$jy, $jm, $jd], e.g. (2026, 8, 20) → [1405, 5, 29].
Jalali::toGregorian($jy, $jm, $jd)→ [$gy, $gm, $gd] — exact inverse.
Jalali::format($date, $format = 'j F Y', $persianDigits = null)Formats any date-ish value in the Jalali calendar. Tokens below.
Jalali::MONTHS / Jalali::WEEKDAYSPersian month names (1-indexed) and weekday names (keyed by PHP's w).

Format tokens: Y year, y 2-digit year, n/m month, j/d day, F month name, l/D weekday name — plus time passthroughs H G h g i s v and A/a (قبل‌ازظهر / بعدازظهر). Escape a token with a backslash.

<mds:timeline> Flux Pro alternative

An open implementation of Flux Pro's timeline: a CSS-grid rail with connector lines, step statuses, coloured indicators, and full-width blocks. Vertically the tracks are [indicator] [gap] [content]; horizontal transposes them to rows. Every offset is a logical property, so the rail sits on the right in RTL and a horizontal timeline flows right-to-left — which is what an Iranian order-tracking strip wants.

<mds:timeline>
    <mds:timeline.item>

Steps and statuses

status drives both the indicator and the rail: a complete item paints the connector up to the next indicator in your accent colour, current gets an accent ring, and incomplete is muted and dims its content to 75%.

<mds:timeline horizontal>
    <mds:timeline.item status="complete">...</mds:timeline.item>
    <mds:timeline.item status="current">...</mds:timeline.item>
    <mds:timeline.item status="incomplete">...</mds:timeline.item>
</mds:timeline>

<mds:timeline size="lg" align="start">
    <mds:timeline.item status="complete">
        <mds:timeline.indicator>@fa(1)</mds:timeline.indicator>
        <mds:timeline.content>
            <flux:heading>سبد خرید</flux:heading>
            <flux:text>کالاها را بررسی کنید.</flux:text>
        </mds:timeline.content>
    </mds:timeline.item>
</mds:timeline>
SubcomponentPropsNotes
timeline.itemstatus, align, sizeRenders an <li> and draws its own connector lines. align and size override the timeline per item; the first item's leading line and the last item's trailing line are hidden automatically.
timeline.indicatorvariant, status, colorPut an icon, number, or text in the slot. variant="bare" strips the circle so a standalone icon can be the marker. color takes any of the 17 Tailwind hues plus zinc, and outranks status.
timeline.content—The cell beside the indicator.
timeline.block—Full-width item body with no indicator column — callouts, cards, comment threads. Direct children span every track.
timeline.subgrid—Inside a block, re-aligns to the timeline's tracks: first child in the indicator track, later children in the content track. Vertical only.

Spacing and baseline

Four CSS custom properties tune the geometry. Set them on the timeline with an arbitrary class:

<mds:timeline class="[--mds-timeline-item-gap:3rem] [--mds-timeline-content-gap:1rem]">...</mds:timeline>
VariableDefaultDescription
--mds-timeline-item-gap1remSpace between items — vertical or horizontal, whichever the timeline is.
--mds-timeline-content-gap0.75remSpace between the indicator and its content (1rem at size="lg").
--mds-timeline-indicator-size2remIndicator diameter (3rem at size="lg").
--mds-timeline-baseline1.25remThe first line's line-height, used by align="baseline" to centre the indicator on it. Raise it for large headings: class="[--mds-timeline-baseline:1.75rem]". This replaces Flux's [data-flux-timeline-baseline] font-size trick.

The timeline's CSS lives in @layer components on purpose. Cascade layers outrank specificity, so an unlayered rule would beat Tailwind's @layer utilities and swallow any class you put on an indicator.
